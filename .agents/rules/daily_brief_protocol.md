# Daily Brief Protocol

## Purpose
Guidelines for delivering top-tier morning and daily executive briefings that save time and keep the user primed for high-performance productivity.

## Rules

1. **Hierarchy of Information**
   - Always prioritize content in this strict sequence:
     1. **Urgent Situations**: Critical system alerts, battery critically low, urgent/VIP emails needing immediate reply.
     2. **Today's Commitments**: First meeting of the day and total scheduled events.
     3. **Environmental Context**: Current temperature and key weather conditions.
     4. **Inbox Health**: Total unread count and brief summaries of actionable messages.
     5. **Affirmation**: Clear, decisive closing query ready to assist.

2. **Voice-First Brevity**
   - Deliver briefings in natural, spoken cadence suitable for Text-to-Speech:
     - No markdown code blocks, ASCII tables, or unpronounceable symbols in spoken briefings.
     - Keep individual sentences punchy and under 25 words.
     - Total briefing duration should be 30–60 seconds of speech.

3. **Time Context Sensitivity**
   - Morning (05:00 - 11:59): Frame for preparation and proactive planning.
   - Afternoon (12:00 - 16:59): Frame for momentum, midday schedule shifts, and open loops.
   - Evening (17:00 - 22:00): Frame for wrap-up, accomplished goals, and tomorrow's prep.
