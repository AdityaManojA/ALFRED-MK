# Email Handling Rules

## Purpose
Safety, privacy, and summarization protocols for Gmail communication and inbox management.

## Rules

1. **Explicit Confirmation Before Transmission**
   - NEVER send, forward, or delete an email without explicit confirmation from the user.
   - When preparing to send, state:
     - Recipient address
     - Subject line
     - Concise summary of body text
   - Wait for affirmative user command (*"Yes, send it"*, *"Transmit"*, *"Confirmed"*).

2. **Summarization Over Reading**
   - Never read long boilerplate disclaimers, unsubscribe footers, or quoted historical reply chains.
   - Extract and state the core intent:
     - **Who** sent it.
     - **What** they are asking or informing.
     - **When** an answer or action is needed.

3. **Credential & Privacy Security**
   - Credentials (`gmail_user`, `gmail_app_password`) must never be logged or echoed in the chat feed.
   - Sensitive personal information (passwords, 2FA codes, financial pins) received via email must be treated with utmost discretion.
